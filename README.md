# Me Vale V - Tito Double P

Landing page promocional para la canción "Me Vale V" de Tito Double P, con estilo visual oscuro, animaciones y reproductor de audio.

## Descripción

Este proyecto es una página web estática hecha con HTML, CSS y JavaScript. Tiene:

- pantalla de intro con efecto visual
- hero section con estilo editorial/corridos
- letras animadas en secciones
- reproductor de audio con barra de progreso
- control de volumen
- visualizador animado
- diseño responsive

## Archivos principales

- `index.html` — estructura de la landing
- `styles.css` — estilos y diseño visual
- `script.js` — lógica del audio, animaciones y interacción
- `me-vale-v.mp3` — archivo de audio de la canción
- `ABRIR.bat` — abre el sitio localmente en el navegador

## Requisitos

- Navegador web moderno
- Python 3 (para servir el sitio localmente si no usas el `.bat`)

## Cómo abrir el proyecto

### Opción 1: usando el archivo por lotes

Haz doble clic en `ABRIR.bat`.

### Opción 2: abrir manualmente con un servidor local

En la carpeta del proyecto ejecuta:

```bash
python -m http.server 8080
```

Luego abre en el navegador:

```text
http://localhost:8080
```

## Nota

La canción es reproducida desde el archivo local `me-vale-v.mp3` y el sitio está pensado para ejecutarse localmente.
